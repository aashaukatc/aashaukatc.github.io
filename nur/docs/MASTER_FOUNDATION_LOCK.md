# NŪR Master Foundation Lock

## Identity

- **Name:** NŪR
- **Descriptor:** Private Access Layer
- **Line:** Private comfort, handled professionally.
- **Domain:** nuur.info
- **Product type:** privacy-first professional wellness appointment platform
- **Primary UX:** private request access → verification → controlled matching → appointment status → feedback/audit

## Market Position

NŪR does not behave like a public marketplace. It behaves like a controlled-access protocol.

The user should feel privacy, trust, modernity, premium access, zero public exposure, and verified professionals only.

## Operating Promise

NŪR connects approved adults with verified wellness professionals through a controlled, private, safety-reviewed appointment flow.

## Non-Negotiable Product Boundary

NŪR supports lawful professional wellness services only.

Agents must reject and avoid:
- sexual service flows
- suggestive service descriptions
- coded language implying illegal or prohibited activity
- public searchable profiles
- unsafe direct messaging mechanics
- off-platform payment pressure
- unlogged sensitive data access

## MVP Definition

The MVP is not a full app. MVP is a trusted acquisition and controlled intake system:

- public website
- request access form
- professional application form
- safety/privacy/terms pages
- Supabase schema
- RLS/security plan
- admin workflow foundation
- manual match process
- audit logs and blocklist design

## Later Definition

Later phases may add Supabase Auth admin dashboard, professional portal, AI intake assistant, pgvector preference memory, Cloudflare Workers edge security, Spline/R3F futuristic hero, analytics, SEO automation, and notification workflows.
