# NŪR Brand System

## Identity

- **Name:** NŪR
- **Descriptor:** Private Access Layer
- **Line:** Private comfort, handled professionally.
- **Voice:** private, calm, premium, futuristic, controlled
- **Visual metaphor:** black-glass protocol, aurora signal, silent luxury

## UI Rules

- Dark mode first.
- No generic spa look.
- No stock-photo dependency in MVP.
- Use abstract privacy grids, radial glows, glass cards, geometric lines.
- Primary CTA: **Request Access**.
- Secondary CTA: **Apply as Professional**.
- Keep one dominant CTA per screen.
- Use short copy.
- Use controlled reveal and quiet luxury cues.

## Copy Rules

Use: private access, verified professionals, quiet booking, professional wellness, controlled appointment flow, safety reviewed.

Avoid: secret fun, open-minded, no limits, sensual, intimate, adult, fantasy, and any coded/suggestive wording.

## Logo Direction

Use a geometric wordmark: **NŪR**.

Logo should feel minimal, premium, secure, architectural, futuristic.

SVGs are included under `assets/svg/`.
