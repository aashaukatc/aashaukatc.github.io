# OMNIS Intelligence

**Source-verified intelligence orchestration for research, operations, simulation, and auditable decision-making.**

OMNIS keeps 28 intelligence domains independently governed, then composes two or more into problem-solving recipes. Each recipe begins with a defined problem, retrieves evidence, records provenance, simulates outcomes, applies policy, and measures results.

## Delivery gates

1. Foundation and Canon Lock
2. Knowledge and Documentation Fabric
3. Platform, Data, and Security Architecture
4. Product Experience and Wireframes
5. Process, Journey, and Prototype Validation
6. Implementation and Production Readiness

## Source-of-truth ownership

- Notion: gates, registry, decisions, and operating knowledge.
- GitHub: code, specifications, migrations, infrastructure definitions, and documentation source.
- Google Drive: stakeholder-facing deliverables and exports.
- Figma and FigJam: design system, wireframes, diagrams, journeys, and interactive prototypes.
- Canva: executive communication assets.
- Supabase: identity, tenant-aware operational data, storage, and vector retrieval.
- AWS: commercial cloud infrastructure and asynchronous processing.
- Replit: interactive reference prototype.
- Google Calendar: gate-review cadence.

## Visual system

OMNIS uses the **Obsidian Aurora** interface system: deep graphite canvases, translucent glass surfaces, cyan intelligence signals, violet synthesis signals, Space Grotesk display typography, Inter interface typography, and JetBrains Mono for evidence and data.
